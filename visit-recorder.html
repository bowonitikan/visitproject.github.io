Panduan cepat Google Apps Script
  1. Buka Google Sheets baru → catat ID dari URL
  2. Menu Extensions → Apps Script
  3. Paste kode GAS (tersedia saat klik tombol di bawah)
  4. Ganti SHEET_ID dengan ID Sheets kamu
  5. Deploy → New deployment → Web app → Anyone → Deploy
  6. Salin URL → paste di kolom "URL Web App" di atas
